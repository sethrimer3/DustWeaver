# Hand-Drawn Map Prototype — Greybox Notes

Companion notes for `hand_drawn_dustweaver_map.dwcampaign.json`, generated from
the April 26, 2026 hand-drawn "Dust, Wurm" map sketch. This is a greybox: macro
layout, room graph, gates, and mechanics placement — not final art or tuning.

Load from **Main Menu → Custom Campaigns** (auto-discovered from this folder).

## Graph deviations from the sketch spec

- `room_lower_water_vines_gate` was referenced once in the spec's connection
  list but is not in the 30-room list — dropped. `room_ice_water_vines`
  connects left (ice entry) and right (light/dark shaft) only.
- Redundant edges collapsed to a single authored path:
  - `speed_check_water → ice_zone_entry` routes through `speed_check_exit`.
  - `dark_zone_lower_entry → golden_dust_region` routes through `dark_zone_main`.
  - `overgrown_upper → magma_entry` dropped (magma is reached via the shaft).
- `golden_dust_region ↔ grapple_vault_region` is a vertical connection,
  matching the suggested world-map coordinates.
- `room_lower_caves_swing` has two left doors: an elevated ledge to
  `lower_caves_reset` and a floor-level door to `falling_block_puzzle`.

## Regeneration

Generated by `scripts/generate-hand-drawn-campaign.mjs` (run from the repo
root: `node scripts/generate-hand-drawn-campaign.mjs`). Deterministic geometry:
3-block floors with door gaps, ledges for elevated doors, one-way platform
stacks under every up-transition, greedy rect compression. Regenerating
overwrites hand edits — once you start refining in the in-game editor (whose
Export Campaign JSON round-trips this file), treat the JSON as the source of
truth and retire the script.
